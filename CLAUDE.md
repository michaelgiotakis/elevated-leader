# HERO IMAGE DELIVERY RULES

Hero imagery is part of the emotional entry experience and must render immediately with the page.

Implementation rules for cinematic hero imagery:

- Use local WebP assets for editorial hero imagery
- Preserve cinematic tonal quality and atmospheric gradients
- Use priority on above-the-fold hero images only
- Use unoptimized={true} for already-optimized local editorial hero WebP assets
- Preserve blur placeholders and smooth atmospheric transitions
- Preserve existing object-fit/object-position composition rules
- Preserve cinematic rendering quality over aggressive compression

Avoid:
- oversized PNG hero assets
- unnecessary /_next/image processing on already-optimized local WebP hero imagery
- delayed hero-image pop-in
- marking non-hero images as priority
- unnecessary dynamic optimization pipelines that damage emotional pacing

Reason:
Performance perception affects luxury perception within the editorial ecosystem.
Hero imagery is compositional infrastructure, not decorative media.
