# THE ELEVATED LEADER — PROJECT RULES

You are building a premium, high-conversion marketing website for a luxury coaching brand called "The Elevated Leader".

## BRAND FEEL
- Warm minimalism meets strategic luxury
- Clean, spacious, editorial, high-end
- No startup SaaS look
- No bright colors or playful UI
- Everything should feel intentional and premium

---

## TYPOGRAPHY

### Fonts
- H1: Playfair Display
- H2–H4: Montserrat Bold / SemiBold / Regular
- Body: Montserrat Regular

### Sizing (Desktop-first)
- H1: 64px
- H2: 40px
- H3: 28px
- H4: 20px
- Body: 16–18px

### Rules
- Large hero headings using Playfair
- Clean readable body text
- Consistent spacing between text blocks
- Avoid cramped layouts

---

## COLOUR SYSTEM

### Core Colours
- Obsidian: #060708 (primary dark)
- Ivory Veil: #F6F1E9 (primary light background)
- Warm Stone: #D4C7B7

### Accent Colours
- Muted Rose: #C98C8C (Identity)
- Rosewood: #7B4444
- Bronze: #B8864C (Leverage)
- Eucalyptus: #3E5F52 (Leverage)
- Slate: #323847 (Structure)

### Rules
- Use mostly neutral palette
- Accents used sparingly
- No random colours
- High contrast, clean sections

---

## LAYOUT SYSTEM

- Max width: 1280px
- 12-column grid
- Large vertical spacing between sections
- Clean section stacking (no clutter)
- Generous padding

---

## COMPONENT STYLE

### Buttons
- Primary: Bronze background
- Secondary: Outline style
- Clean, minimal, strong

### Cards
- Light background
- Soft borders
- Subtle shadows only if needed

---

## PAGE STRUCTURE (CRITICAL)

Always follow this structure exactly:

### Pages to build:
- Home
- Diagnostic
- Courses
- Individual Course
- Method
- FAQ
- Flagship
- Checkout / Thank You

### Rules:
- Do NOT invent new sections
- Follow provided section order exactly
- Maintain clear hierarchy
- Use CTA sections consistently

---

## DEVELOPMENT RULES

- Use Next.js App Router
- Use Tailwind CSS
- Build reusable components
- Keep code clean and modular
- Prioritize readability and structure
- Mobile responsive by default

---

## UX RULES

- Clear CTA flow
- No clutter
- Strong visual hierarchy
- Easy to scan
- Premium feel over flashy design

---

## NEVER DO

- No bright gradients
- No neon colours
- No SaaS-style UI blocks
- No cluttered layouts
- No inconsistent typography
- No random spacing

---

## GOAL

Build a premium, conversion-focused website that feels like a high-end strategic brand, not a generic online course site.
