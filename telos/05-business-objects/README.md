# 05 — Business Objects

This section defines the canonical entities the business operates with — the nouns of the operating system.

## What belongs here

- Client (definition, types, statuses)
- Product (definition, types, delivery formats)
- Offer (structure, components, pricing logic)
- Programme (multi-stage delivery containers)
- Session (individual delivery units)
- Transaction (purchase, refund, subscription events)
- Asset (content, tools, resources delivered to clients)
- Any other named entity that appears across pipelines, automations, or reporting

## Why this exists

Without canonical object definitions, every system uses slightly different language and logic for the same thing. This section ensures every tool, automation, and team member is operating on the same definitions.
