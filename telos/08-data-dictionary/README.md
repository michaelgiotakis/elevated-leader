# 08 — Data Dictionary

This section defines every data field, property, and metric used across the ecosystem — the single source of truth for what data means.

## What belongs here

- Field-level definitions for every property on every business object (client, lead, transaction, etc.)
- Accepted values and data types for each field
- Where each field lives (which system owns it)
- How fields map across systems when data is synced or transferred
- Metric definitions (e.g. what exactly counts as a "conversion", "active client", "revenue")
- Data quality standards and validation rules

## Why this exists

Data only becomes useful when everyone agrees on what it means. This dictionary prevents reporting inconsistencies, broken integrations, and silent data corruption across the technology stack.
