# 16 — Implementation Roadmap

This section contains the phased implementation plans for building, populating, and evolving the TELOS operating system and the business infrastructure it describes.

## What belongs here

- Current state assessment (what is built, what is partially built, what is missing)
- Prioritised implementation phases
- Phase-level goals and completion criteria
- Dependencies between implementation items
- Timeline estimates and milestones
- Resource requirements per phase
- Risk and constraint log
- Progress tracking against the roadmap

## Why this exists

TELOS describes what the business should be. The roadmap describes how it gets there. Without a roadmap, the operating system remains aspirational. With one, every section becomes an actionable commitment with a clear path to completion.
